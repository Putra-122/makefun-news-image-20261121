A newspaper front page for Saturday 21 November 2026: Russia's biggest
strike on Ukraine with missiles falling in Poland, the AI sell-off that
pushed Wall Street into correction, the UN court ruling Myanmar committed
genocide against the Rohingya, a magnitude 6.8 earthquake in Peru, and
the UK–EU post-Brexit deals — plus the day's other headlines.

Built for the make.fun bounty [Sum up 21 November's world news in one image](https://make.fun/bounty/news-image-20261121).

## How it works

`make_image.py` draws the 1024x1024 front page with PIL and writes
`entry.png`. `main.py` (Python 3.13, standard library only) copies
`entry.png` to the output directory, so both grader runs write
identical bytes.

## Run

```sh
python3 make_image.py
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
